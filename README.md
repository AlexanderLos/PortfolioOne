# Portfolio

Personal site — Alexander De Los Santos.

Built with Next.js 16 (App Router), TypeScript (strict), Tailwind CSS v4. Deployed on Vercel.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `app/` — routes, layout, metadata, OG image, sitemap
- `components/` — section components (hero, about, work, contact, footer, nav)
- `lib/data.ts` — work timeline data
- `public/` — static assets (resume.pdf)
